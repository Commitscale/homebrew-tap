# Commitscale's Homebrew tap

`cscale`, Commitscale's command line, for macOS and Linux:

```sh
brew tap commitscale/tap https://commitscale.com/commitscale/homebrew-tap.git
brew install commitscale/tap/cscale
```

Each release updates `Formula/cscale.rb`. It pins every build by its SHA-256. The macOS builds are signed and notarized.
